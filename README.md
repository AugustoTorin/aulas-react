# 📖 Aulas de React

Repositório destinado ao registro dos estudos e exercícios desenvolvidos durante meu aprendizado de React e Next.js.

O conteúdo está organizado por capítulos, acompanhando a evolução dos assuntos estudados em aula. Cada capítulo possui os próprios exercícios.

## 📚 Organização

| Diretório | Descrição |
|---|---|
| `exercicios-cap-um/` | Primeiro capítulo de estudos |
| `exercicios-cap-dois/` | Segundo capítulo de estudos |
| `exercicios-cap-tres/` | Terceiro capítulo de estudos |

## 🔧 Tecnologias e ferramentas

- React
- Next.js
- JavaScript
- HTML
- CSS
- Git e GitHub

## 💻 Como executar os exercícios

Cada capítulo possui sua própria aplicação.

Para executar um capítulo, entre no diretório correspondente, instale as dependências e inicie o servidor de desenvolvimento.

```bash
cd exercicios-cap-um
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

Para executar outro capítulo, basta entrar em seu respectivo diretório.

## 💡 Objetivo

Este repositório funciona como um histórico de aprendizado, permitindo acompanhar a evolução dos estudos, consultar implementações anteriores e reforçar os conceitos aprendidos ao longo da formação em desenvolvimento web.
